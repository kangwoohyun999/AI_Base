# CNN을 활용한 한국 음식 자동 분류
**강우현 · 202404178 · 인공지능융합공학부**
참고: keon/3-min-pytorch Chapter 5

---

## 프로젝트 소개

직접 수집한 한국 음식 사진 5종을 CNN으로 학습해 자동 분류하는 프로그램입니다.
PyTorch의 `ImageFolder`를 사용해 폴더 구조만 맞추면 어떤 이미지든 바로 학습할 수 있습니다.
학습 전(랜덤 가중치)과 학습 후의 인식률을 비교해 CNN 학습 효과를 정량적으로 검증합니다.

**분류 대상 (5종)**
- 김치찌개 / 된장찌개 / 비빔밥 / 삼겹살 / 라면

**Fashion MNIST와 차이점**

| 항목 | Fashion MNIST | 이번 프로젝트 |
|------|--------------|--------------|
| 데이터 | 자동 다운로드 | **직접 수집한 사진** |
| 이미지 | 28×28 흑백 | **64×64 컬러(RGB)** |
| 입력 채널 | 1채널 | **3채널 (R·G·B)** |
| 데이터 증강 | 없음 | **회전·반전·색감 변화** |

## 실행 방법

### 1단계 — 라이브러리 설치

```bash
pip install torch torchvision matplotlib scikit-learn seaborn
```

---

### 2단계 — 이미지 수집 및 폴더 구성

아래 구조로 폴더를 만들고 이미지를 넣습니다.

```
food_dataset/
├── train/
│   ├── 김치찌개/   ← 이미지 50~100장
│   ├── 된장찌개/
│   ├── 비빔밥/
│   ├── 삼겹살/
│   └── 라면/
└── test/
    ├── 김치찌개/   ← 이미지 10~20장
    ├── 된장찌개/
    ├── 비빔밥/
    ├── 삼겹살/
    └── 라면/
```

**이미지 수집 방법**
- 구글 이미지 검색 → 우클릭 → 다른 이름으로 저장
- 직접 촬영한 음식 사진도 가능
- jpg / jpeg / png 모두 지원

### 4단계 — 출력 결과 확인

실행이 완료되면 터미널에 아래 내용이 출력됩니다.

```
▶ 학습 전 인식률 측정 (랜덤 초기화 가중치)
  Accuracy: 약 20%  ← 무작위 예측 수준

▶ 학습 시작
  [Epoch 1/5] Train 42.0%  Test 48.0%  ...
  [Epoch 5/5] Train 76.5%  Test 80.0%  ...

▶ 학습 전/후 인식률 비교
  학습 전 : 20.xx%
  학습 후 : 75~85%
  향상폭  : +55~65%p
```

그래프 3개가 자동 저장됩니다.

| 파일명 | 내용 |

| `training_curves.png` | Loss · Accuracy 학습 곡선 |

| `before_after.png` | 학습 전/후 인식률 바 차트 |

## 주요 설계 포인트

- **SGD + momentum 0.5** — 교재(keon/3-min-pytorch)와 동일한 옵티마이저, 완만한 수렴으로 과적합 억제
- **Dropout(0.6)** — 강한 정규화로 Train ≈ Test 유지
- **데이터 증강** — 이미지 수가 적어도 과적합 없이 학습 가능
- **FC 크기 자동 계산** — `IMG_SIZE` 값만 바꾸면 모델 구조 자동 조정
